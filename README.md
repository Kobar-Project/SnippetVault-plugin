KoBar is a versatile platform designed to host a rich ecosystem of plugins, seamlessly integrating powerful tools directly into your daily workflow. As a core extension for this ecosystem, **Snippet Vault** transforms KoBar into an indispensable coding and text-expansion utility.

## What is Snippet Vault?

Snippet Vault is a secure, categorized storage system designed specifically for developers, writers, and power users. It allows you to save frequently used text blocks, API keys, code templates, and bash scripts. When you need them, they are just one click away in your KoBar sidebar, avoiding the need to dig through text files or heavy note-taking apps.

## Key Features

- **Local Encryption:** All sensitive snippets are encrypted locally using AES-256 before hitting the disk. Your data remains completely private and secure.
- **Categorization:** Organize your snippets using custom tags, folders, or color codes for rapid visual retrieval.
- **Syntax Highlighting:** Integrated code blocks automatically detect the programming language and apply proper syntax highlighting.
- **One-Click Copy:** Easily inject a snippet straight into your system clipboard, or bypass the clipboard completely and type it directly into your active window.
- **Fuzzy Search:** Features a blazing-fast fuzzy search bar that instantly filters your vault based on titles, content, or tags.
- **Multi-Language:** Fully localized UI supporting 10 different languages globally.

## Configuration & Usage

1. **Access the Vault:** Click the Snippet Vault icon in the KoBar sidebar.
2. **Add a Snippet:** Click "New Snippet" to open the editor. Paste your code, assign a title, language type, and relevant tags.
3. **Retrieval:** Search for your snippet using the fuzzy finder. 
4. **Copying:** Click the copy icon to add the text to your system clipboard, or use the "Send to KoBar Slot" to prepare it for sequential pasting via the Clipboard Manager plugin.
5. **Security Settings:** Set a Master Password in the Vault settings to enable AES-256 encryption.
